# Обоснование конфигурации Terraform + Docker

## Выбор технологий

- **Docker** выбран за его лёгкость в развёртывании и изоляции приложений. Контейнеризация упрощает управление зависимостями и обеспечивает воспроизводимость среды.
- **Terraform** - средство описания инфраструктуры как кода: конфигурация сети, томов и контейнеров фиксируется в декларативном виде, легко ревьюится и повторно применяется.

## Ресурсы
Автоматически разворачивается вся необходимая конфигурация: network, disk, computed cloud VM, container registry. 
Для VM выделено 2Gb оперативной памяти, 2 ядра процессора и 10ГGb диск - этого вполне достаточно для работы одного 
инстанса небольшого приложения витрины в Docker.

## Разворачивание приложения
В дальнейшем ci-cd пайплан будет собирать Docker Image из исходного кода и загружать его в Container Registrygit
